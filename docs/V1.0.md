# Veyrix V1.0 — Submission Prototype

## Product scope

Veyrix is an Autonomous Strategy Research Lab for SOL. It combines live public market context, local paper trading, historical backtesting, strategy comparison, robustness analysis, and reproducible research reporting. The V1.0 release is a presentation and release-hardening milestone; it does not change strategy, execution, risk, validation, or scoring formulas.

## Major capabilities

- Live Coinbase SOL-USD market data and local paper portfolio
- Momentum, Moving Average Crossover, and Mean Reversion strategies
- OHLC-aware backtests with fees, slippage, stops, targets, and long-only sizing
- Full and exposure-matched buy-and-hold benchmarks
- Sensitivity, walk-forward, multi-regime, extended, and multi-anchor validation
- Performance, robustness, overfitting, failure, exposure, and evidence analytics
- Deterministic run IDs, manifests, fingerprints, normalized artifacts, caching, and exports
- Dedicated Research Workspace with scorecards, reports, demo view, and saved-run history

## Architecture

The product uses Next.js App Router, React, and strict TypeScript. Public Coinbase Exchange APIs supply market data. Browser persistence owns the live paper account. Server-side research receives immutable historical datasets and does not access or mutate live paper state. Research storage is layered: process memory first, then an optional local filesystem store. Normal inspection uses compact STANDARD detail and retrieves heavier artifacts lazily.

## Strategies and methodology

All three strategies run under identical capital, position sizing, fee, slippage, risk, and benchmark assumptions. Validation remains chronological and includes overlapping, non-overlapping, expanding walk-forward, embargoed, regime, and multi-anchor analysis. Experimental Veyrix scores describe configured research dimensions and are not industry-standard finance metrics.

## Safety boundary

Veyrix is paper trading and simulation only. It does not connect wallets, request wallet secrets, execute exchange orders, submit blockchain transactions, move funds, use leverage or margin, or create short positions. Nothing in the interface is investment advice.

## Deployment

The application builds as a standard Next.js project and requires no secret for public market data. On serverless deployments, memory cache is best effort and filesystem durability is not guaranteed. An external durable provider is not required or bundled. Deploy with the committed lockfile using `npm ci` and `npm run build`; on Vercel, import the repository and retain the default Next.js settings.

## Known limitations

Historical simulations cannot model exact intrabar paths, variable liquidity, spread, market impact, or latency. Coinbase data can be incomplete or temporarily unavailable. Rolling windows may overlap. Regime labels and research scores are deterministic heuristics, not formal statistical significance. Long research jobs can be compute intensive, and durable production storage requires future infrastructure.

## Release validation

The release gate covers ESLint, strict TypeScript, the complete deterministic suite, production build, HTTP smoke tests, API checks, lazy artifacts, report generation, and confirmation that research does not mutate live paper state. Final measured results are recorded in the V1.0 completion report.
