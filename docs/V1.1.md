# Veyrix V1.1 — Live Paper Trading Terminal

## Scope

V1.1 makes the existing simulation visibly operate over time without changing any strategy, risk, backtest, or research formula. The Dashboard now centers on a live SOL/USDC terminal with charting, closed-candle automation, one shared paper portfolio, manual paper controls, and read-only wallet identity.

## Market candles

Coinbase Exchange public SOL-USD candles require no API key. Native intervals used are 1m, 5m, 15m, 1H, 6H, and 1D. Veyrix builds 30m from two 15m candles, 4H from four 1H candles, and 12H from two 6H candles using first open, maximum high, minimum low, final close, summed volume, and the UTC bucket start. Invalid OHLC and duplicate timestamps are removed. The chart refreshes every 15–60 seconds depending on timeframe; the latest candle may update while open.

## Chart

Lightweight Charts 5.2.1 renders candlestick and line modes client-side. Up candles/wicks are green, down candles/wicks red, and unchanged candles receive neutral volume treatment. Volume appears on its own price scale. Manual and autonomous entries/exits produce chart markers. Open positions show labeled entry, 2% stop, 4% target, and live-price lines. Chart timeframe is independent of automation timeframe.

## Closed-candle automation

Automation fetches the selected timeframe and evaluates only candles whose start plus interval is at or before the current time. IDs use `strategyId:timeframe:candleTimestamp`, and processed IDs persist in `veyrix.automation.v1`. Each qualifying candle produces the selected strategy's real BUY, SELL, or HOLD result. BUY opens the existing 10% long-only paper allocation when flat. SELL closes an open position and never shorts short. HOLD records no transaction. After a browser restart, only the newest safe closed candle is considered; missed historical candles are not replayed.

When automation is OFF, strategy entries and strategy SELL exits are disabled. Existing live stop-loss and take-profit monitoring remains active. Manual positions obey the same one-position and risk rules and may be closed by strategy SELL when automation is ON.

## Manual paper trading

Manual BUY accepts a virtual USDC amount, previews estimated SOL and remaining virtual USDC, and requires an explicit simulation confirmation. SELL ALL closes the whole virtual position and also requires confirmation. Both actions use the current public SOL price and the same persisted paper portfolio. No fees were added to live paper behavior in V1.1.

## Read-only wallet

The official Solana wallet-adapter React architecture uses Wallet Standard discovery with no legacy wallet bundle. Phantom, Solflare, and Backpack paths are shown. Veyrix invokes connect, disconnect, public-key display, and public balance lookup only. It does not invoke message signing, transaction signing, `sendTransaction`, deposits, withdrawals, or paper-account funding. The public wallet and `$10,000 Virtual USDC` account are visually separated.

## Persistence and migration

Existing `veyrix.paper-portfolio.v1` records remain readable; legacy trades without source metadata retain their history and display as legacy autonomous strategy trades. New trades carry source, strategy/timeframe where applicable, signal candle, and `SPOT` market type. Automation settings and processed candle IDs use a separate validated versioned schema.

## Limitations

The terminal polls REST APIs rather than a streaming order book. Public RPC balance lookups may be rate-limited. Open-candle chart changes never trigger execution. Browser-local automation runs only while the page is open; restart behavior intentionally avoids backfilling missed trades. Wallet identity is not authentication. Futures, leverage, margin, and short selling remain unavailable.
