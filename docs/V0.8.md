# Veyrix V0.8 multi-strategy lab

Veyrix remains paper-trading and historical simulation only. It never connects wallets, moves funds, sends orders or transactions, or supports leverage, margin, or short selling. Historical results do not predict future performance.

## Generic strategy architecture

Every registered strategy has a stable ID, name, description, minimum observation count, configuration, and an evaluate function. Evaluators receive chronological close-price observations and return a validated BUY, SELL, or HOLD decision with confidence, reason, and strategy-specific metrics. The shared backtest engine handles positions, OHLC risk checks, fees, slippage, analytics, and benchmarking. Invalid or throwing evaluators fail to HOLD without corrupting other runs.

The registry contains momentum, moving_average, and mean_reversion. Single mode supplies one registry entry to the engine. Compare mode fetches once, normalizes and freezes one candle set, and runs three isolated portfolios with the same configuration.

## Strategy rules

### Momentum Agent

Uses the existing 6-observation minimum and up to 12 observations. BUY requires short-term change of at least +0.35% and price at least +0.15% above the recent average. SELL requires both corresponding negative thresholds. Otherwise it holds.

### Moving Average Agent

Uses a 5-observation fast SMA and 12-observation slow SMA. It needs 13 observations to compare current and previous relationships. BUY occurs only when the previous fast SMA was at or below the slow SMA and the current fast SMA is above it. SELL is the inverse crossover. Merely remaining above or below produces HOLD. Confidence combines bounded SMA separation and recent directional movement.

### Mean Reversion Agent

Uses a 12-observation rolling average. BUY occurs at a deviation of -1.00% or lower. SELL occurs when deviation returns to 0.00% or above. Values between those thresholds HOLD. SELL while flat never creates a short position. Confidence is a bounded function of deviation magnitude.

## Fair comparison

All agents receive the same historical candles, timeframe, $10,000 starting balance, 10% position sizing, 0.10% fee per side, 0.05% adverse deterministic slippage, 2% stop, 4% target, long-only restriction, and STOP_FIRST intrabar collision policy. Buy and Hold SOL uses the same $10,000 and transaction costs. The leaderboard does not invent trade statistics for the benchmark.

Return vs Buy and Hold is strategy return percentage minus benchmark return percentage.

## Veyrix Score (Experimental)

This transparent experimental score is not an industry-standard performance metric. Each component is clamped to 0 through 100:

- Return score = clamp((return % + 20) / 40, 0, 1) times 100.
- Drawdown score = 100 minus clamp(max drawdown % / 20, 0, 1) times 100.
- Profit-factor score = clamp(profit factor / 3, 0, 1) times 100; unavailable is 0.
- Expectancy score = clamp((expectancy % + 2) / 4, 0, 1) times 100; unavailable is 0.
- Total = 35% return score + 25% drawdown score + 20% profit-factor score + 20% expectancy score.

The final score is always between 0 and 100. It complements rather than replaces the separate highest-return, lowest-drawdown, highest-profit-factor, and highest-expectancy labels.

## Shared execution and benchmark assumptions

OHLC risk checks, STOP_FIRST ambiguity handling, fee/slippage accounting, timeframe mappings, and full-capital cost-adjusted Buy and Hold remain as documented in V0.7. Exact intrabar paths, spreads, liquidity, order-book depth, latency, market impact, taxes, and changing fee tiers are not modeled. Strategies are evaluated at candle close; positions opened at a close cannot react to that candle's earlier high or low.
