## Corrections during this review

- Migrated agents recognize both prior candle-ID formats, preventing replay after reload without suppressing independent agents.
- Aggregate deployed agent capital excludes manual, unassigned, and detached open positions.
- Agent equity curves include their zero baseline, making a single completed trade drawable.
- Restored migration changes are saved immediately, even when an account snapshot already exists.
- Invalid agent data received through cross-tab storage events stops mutations instead of silently accepting an empty agent store.

## Remaining known limits

The local-storage lease is not an atomic cross-tab lock. Agents require an open controlling browser tab; browser-local guest storage is not a cloud backup. Public-provider availability and modeled execution remain limitations. This acceptance is a desktop Chrome pass, not an exhaustive browser/device or cross-tab race audit. Research loading/navigation were checked; a new long-running historical research job was not required for this release check. Screenshot captures remain optional; recommended views are the multi-agent overview, BTC/ETH/SOL cards, comparison, per-agent analytics/equity, and shared capital/open positions.
