# Veyrix V0.9 — Strategy Robustness Lab

Veyrix remains a paper-trading and historical-simulation application. It never connects a wallet, moves funds, submits an order, uses leverage, or opens a short position. Historical results do not predict future performance.

## Architecture

V0.9 adds a backtest-only optimization layer under `src/lib/optimization`. Parameter schemas create configured instances of the existing generic strategies; all simulation still passes through the single V0.8 backtest and execution engines. The live paper portfolio, daily-loss state, persistence keys, and processed evaluation IDs are never read or written by sensitivity or walk-forward runs.

Historical candles are normalized once per analysis. Every parameter configuration and every strategy receives the same chronological, immutable OHLC dataset, $10,000 starting balance, 10% sizing, 2% stop, 4% target, 0.10% fee per side, 0.05% adverse deterministic slippage, long-only constraint, and `STOP_FIRST` collision policy.

## Backtest-only parameter grids

| Strategy | Parameter | Valid grid values | Default |
|---|---|---:|---:|
| Momentum | Momentum threshold (%) | 0.20, 0.35, 0.50 | 0.35 |
| Momentum | Average deviation threshold (%) | 0.10, 0.15, 0.25 | 0.15 |
| Moving Average | Fast period | 3, 5, 7 | 5 |
| Moving Average | Slow period | 9, 12, 15 | 12 |
| Mean Reversion | Lookback period | 8, 12, 16 | 12 |
| Mean Reversion | Buy deviation (%) | -0.75, -1.00, -1.25 | -1.00 |
| Mean Reversion | Sell/reversion threshold (%) | -0.10, 0.00 | 0.00 |

This produces 9 Momentum, 9 Moving Average, and 18 Mean Reversion combinations. Moving Average combinations are accepted only when fast period is below slow period. Mean Reversion requires the buy threshold to remain below the sell threshold. Values outside the schema are rejected.

Sensitivity analysis reports the default configuration, highest-return configuration, highest-Veyrix-Score configuration, and lowest-drawdown configuration. Highest return is deliberately not treated as universally best.

## Exposure-matched benchmark

The original full-exposure SOL benchmark remains unchanged. The new matched benchmark starts with $10,000, invests 10% ($1,000) into SOL at the first valid close, and holds the remaining 90% as virtual USDC. It liquidates/marks the SOL portion at the final close. Entry and exit use the same 0.10% fees and 0.05% adverse slippage as strategy backtests. Returns and drawdown are expressed against the full $10,000 baseline.

`Return vs Full SOL = strategy return % - full-exposure benchmark return %`

`Return vs Matched Exposure = strategy return % - 10%-exposure benchmark return %`

These values are simple return differences, not CAPM or Jensen alpha.

## Walk-forward methodology

Walk-forward analysis is limited to the 30D dataset. After validation and chronological sorting, `floor(candleCount × 0.70)` candles form the in-sample segment and the rest form the out-of-sample segment. With the typical 121-candle feed, this is 84 in-sample and 37 out-of-sample candles. No candle overlaps and no random shuffle occurs.

The complete parameter grid is evaluated only in-sample. The configuration with the highest experimental Veyrix Score is selected and frozen, then run once using only out-of-sample candles. Parameters are never retuned on the out-of-sample segment.

`Return decay = OOS return % - in-sample return %`

`Score decay = OOS Veyrix Score - in-sample Veyrix Score`

## Parameter Stability (Experimental)

Neighbors are valid grid configurations no more than one declared parameter step from the best-scoring configuration on every parameter axis. For those neighbors:

- `mean return delta = mean(abs(neighbor return - best return))`
- `mean score delta = mean(abs(neighbor Veyrix Score - best score))`
- `return similarity = clamp(100 - 10 × mean return delta, 0, 100)`
- `score similarity = clamp(100 - mean score delta, 0, 100)`
- `Parameter Stability = (return similarity + score similarity) / 2`

The result is bounded 0–100. A configuration without a valid neighbor receives 0 because local stability cannot be established.

## Overfitting Risk — Experimental

The classification is a deterministic heuristic, not a statistical test:

- `HIGH`: stability below 40; or score decay below -30; or positive in-sample return becomes negative OOS with return decay below -1 percentage point.
- `MODERATE`: stability below 70; or score decay below -15; or return decay below -0.5 percentage point.
- `LOW`: none of the above.
- `UNAVAILABLE`: required metrics are missing or non-finite.

## Veyrix Robustness Score — Experimental

- `Return consistency = clamp(100 - 10 × abs(return decay in percentage points), 0, 100)`
- `Drawdown consistency = clamp(100 - 10 × max(0, OOS max DD% - IS max DD%), 0, 100)`
- `Robustness = 40% OOS Veyrix Score + 25% Parameter Stability + 20% Return Consistency + 15% Drawdown Consistency`

The result is clamped to 0–100. This is a transparent Veyrix research heuristic, not an industry-standard or statistically validated measure.

## Known limitations

- Thirty days is a small sample and contains only one chronological holdout.
- A single 70/30 split can be regime-dependent; this is a foundation, not full rolling walk-forward validation.
- Small grids reduce compute and data-mining risk but can miss useful parameter regions.
- Zero-trade configurations have unavailable trade metrics and can still score through bounded fallback components.
- Candle OHLC data does not reveal exact intrabar paths; `STOP_FIRST` remains the conservative collision assumption.
- Fees and slippage are deterministic estimates; liquidity, order-book depth, spread variation, latency, and partial fills are not modeled.
- Exposure matching matches initial capital allocation, not the strategy's time-varying market exposure.
